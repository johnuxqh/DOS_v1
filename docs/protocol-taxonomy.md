# Protocol Taxonomy

Protocols define how drawn exercise cards become a workout.

- **AMRAP:** As many quality rounds or reps as possible in a fixed time. Useful for density and repeatable conditioning.
- **EMOM:** Start work every minute on the minute, then rest for the remaining time. Useful for pacing and controlled quality.
- **Tabata:** Short work-rest intervals, commonly 20 seconds on and 10 seconds off. Best with simple low-skill movements.
- **Pyramid:** Reps climb and then descend. Useful for progressive exposure without requiring maximal effort.
- **Ladder:** Reps increase by a small amount each round. Useful for pacing and measurable progression.
- **Chipper:** Complete a list of cards once in order. Useful for task-priority workouts.
- **Build the Stack:** Add one new card each round, increasing complexity and volume gradually.
- **Density Block:** Repeat a fixed set of reps for quality rounds within a time block.
- **Cardio Sandwich:** Place conditioning work before and after strength or control work.
- **Chaser:** Add a short conditioning finisher after primary cards each round.

Protocol metadata includes time, cards to draw, timer needs, plyometric limits, recommended difficulty, scoring, and safety notes.
